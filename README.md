# quiz-masters
een quiz website waar je quizes kan maken, spelen, uploaden en downloaden
op de start pagina kan je kiezen om een quiz te spelen, maken, of in te loggen bij je account.
als je spelen kiest kan je kiezen tussen quizes op je account en ze te spelen.
vanaf hier kan je ook naar de quiz maken pagina en inlog pagina.
op de inlog pagina kan je inloggen en/of registreren.
en op de quiz pagina kan je nieuwe quizes maken.
